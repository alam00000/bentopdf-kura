## Contributing

Contributors sign a [CLA](https://github.com/alam00000/bentopdf-kura/blob/main/ICLA.md), which the bot prompts for automatically on the first pull request; that is what makes the dual licensing possible. See [CONTRIBUTING.md](https://github.com/alam00000/bentopdf-kura/blob/main/CONTRIBUTING.md) for the workflow, and please include the PDF that reproduces any bug you fix.
